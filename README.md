# WoocLight

Application PHP et JavaScript natif pour animer des ateliers participatifs.

- [Installation FTP et guide d’atelier](wooclight/README.md)
- [Archive FTP](wooclight.zip)
- Tests complets et isolés : `python3 tests/run.py` (PHP, Python, Node, Playwright et Chromium).
- Reconstruction de l’archive : `python3 scripts/package.py`.

Aucune dépendance à installer sur l’hébergement. PHP 8.1 ou supérieur et Apache avec `.htaccess`.
